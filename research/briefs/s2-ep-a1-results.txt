Owner decisions (2026-10-28):
- XBRL from the quarter ending 2020-03-31 onward. No parsing of the pre-XBRL HTML pages.
- No Alembic in the repo: hat_financial_result is a SQLAlchemy model created the way the repo creates tables (create_all + idempotent DDL in backend/app/hat/schema.py). Append-only: revisions are new rows (version, supersedes_id), never updates.
- public_at = the results announcement broadcast time from corporate-announcements ("Financial Result Updates", or "Outcome of Board Meeting" in the Integrated era), not the listing's broadCastDate (wrong before 2022, A0 section on timestamps). xbrl_at from the XBRL stamp date / creation_Date.
- Reusable pipeline: commit the fetch + parse + derive as rerunnable repo code with one CLI entry point (e.g. `python -m app.hat.data.results fetch|parse|derive --from --to [--symbols]`), incremental (only filings not yet stored; raw files cached by sha256 under $HAT_DATA_ROOT/raw/nse-results/ and never re-downloaded), resumable after interruption, paced like A0 (~1 req/s, back off on 401/403/429). Document the command in the data docs so future quarters are one command.
- Gaps: for a company-quarter that NSE does not list or whose XBRL fails (e.g. the June 2022 quarter missing for 5 of 19 symbols in A0), backfill revenue, net profit and EPS from screener.in company pages (consolidated and standalone pages). Rules: check robots.txt and use only pages that need no login (never log in, never handle credentials); pace ~1 request per 3 s, cache raw pages. Backfilled rows carry source=screener, are never used where an NSE row exists for the same (instrument, period_end, basis), and their public_at = the NSE results announcement time for that quarter if found, else the regulatory deadline (quarter end + 45 days, +60 for Q4) at 23:59 IST with public_at_estimated=true. Find out and report how far back screener's public pages go; if the needed quarters are not public, say so and leave the gap flagged rather than guessing. In repo docs refer to it as "secondary source".
