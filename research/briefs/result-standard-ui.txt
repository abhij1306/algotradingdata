A parallel builder (hat/result-standard-backend) is writing the folders and these routes; code against this contract and rebase onto it once it merges (regenerate the API types from its openapi.json then):

   - GET /api/hat/backtests/runs/{run_id}/files/{name}, name in trades|equity|refusals|signals|stocks → CSV.
